# Workflow: Plan a WebOS Feature

1. Read the PRD, architecture and relevant subsystem documentation.
2. Inspect the current implementation and task board.
3. Identify host-side, emulator-side and guest-side responsibilities.
4. List assumptions, upstream API requirements and compatibility risks.
5. Break the work into small tasks with observable acceptance criteria.
6. Identify tests and a rollback strategy.
7. Update the task board before implementation.
8. Ask for clarification if scope or architecture must change.
