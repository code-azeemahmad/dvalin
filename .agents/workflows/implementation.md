# Workflow: Implement a WebOS Feature

1. Confirm the task and acceptance criteria.
2. Inspect related code and existing tests.
3. Implement the smallest complete vertical slice.
4. Keep emulator lifecycle and guest interactions in dedicated services.
5. Add tests for success, failure and cleanup paths.
6. Run relevant lint, typecheck, unit and integration checks available in the repository.
7. Manually test browser/emulator behaviour when automation cannot cover it.
8. Record exact test evidence and limitations.
9. Update tasks, progress and relevant technical documentation.
