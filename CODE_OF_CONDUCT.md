# WebOS Community Code of Conduct

## Purpose & Scope

The WebOS community brings together developers, students, educators, and systems enthusiasts exploring operating systems, virtualization, and web technologies. We are committed to fostering a respectful, collaborative, and inclusive environment across all project discussions, issue trackers, code reviews, and community channels.

---

## Community Standards

To ensure a productive and welcoming space, all contributors and participants agree to uphold the following guidelines:

- **Constructive & Courteous Engagement:** Treat everyone with kindness and professional respect. Focus critique on technical concepts, code architecture, and evidence, rather than individuals.
- **Architectural Respect:** Honor the core architectural commitments of WebOS—genuine emulation of the Linux guest kernel, distinct host/guest boundaries, and client-side isolation.
- **Responsible Security Practices:** Practice responsible vulnerability disclosure. If you identify an issue related to the emulator sandbox, local proxy middleware, or private network boundaries, report it to the maintainers confidentially before public discussion.
- **Inclusive Mentorship:** Support newcomers and contributors of all skill levels by sharing knowledge, providing actionable code reviews, and explaining design rationale patiently.

---

## Unacceptable Conduct

The following actions are strictly prohibited in all project spaces:

- Harassment, intimidation, discriminatory comments, or personal insults.
- Trolling, bad-faith disruptions, or sustained derailment of technical discussions.
- Publishing private information, personal data, or confidential credentials without explicit consent.
- Submitting deliberately malicious code, payloads, or unverified claims.

---

## Reporting & Enforcement

Project maintainers are responsible for upholding these community values:

1. **Reporting:** If you experience or witness behavior that violates this code of conduct, please reach out to the project maintainers through private contact or the repository's reporting channels.
2. **Review:** All reports will be evaluated promptly, confidentially, and impartially.
3. **Actions:** Maintainers may issue private warnings, edit or delete comments, or suspend participation in the project for serious or repeated violations.
